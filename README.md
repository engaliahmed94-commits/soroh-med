# soroh med | صروح ميد

نموذج تفاعلي لتطبيق سوق الأجهزة والمستلزمات الطبية في العراق، يربط الشركات بالأطباء.
Interactive prototype of a medical devices and supplies marketplace for Iraq.

## المميزات | Features
- أقسام في الأعلى: تصوير، قلب ومراقبة، مختبر، تعقيم، تنفس، أسنان، مستلزمات، كواشف، غرف عمليات
- بحث، وفلتر "موثّقة فقط"
- طلب صيانة مع تتبع الحالة
- توثيق الشركات (طلب + حالة المراجعة)
- بيع جهاز، واطلب جهازاً
- إضافة صورة لأي جهاز من الهاتف

## التشغيل | Run
افتح `index.html` في المتصفح. لا يحتاج تثبيت.

## النشر | Deploy
GitHub Pages: Settings > Pages > Deploy from a branch > `main` / root.

> نموذج أولي: أسماء الشركات تجريبية، وزر الإرسال لا يتصل بخادم بعد.
